## 🐛 Sample Bug Report

**Bug ID:** BUG-007  
**Application:** SauceDemo  
**Module:** Checkout  
**Severity:** High &nbsp;|&nbsp; **Priority:** P1  

**Summary:** Checkout completes without requiring a last name field

**Steps to Reproduce:**
1. Log in as `standard_user`
2. Add any item to the cart
3. Proceed to checkout
4. Enter first name only, leave last name blank
5. Click Continue

**Expected:** Validation error — last name is required  
**Actual:** Checkout proceeds to the next step without error  
**Environment:** Chrome 120, Windows 11
